## Notas

- **2026-08-04** — Primera corrida del agente. Precedente leído: `specs/11-controles-tactiles.md` (Implementado) — dejó explícitamente fuera de alcance el rediseño responsive general de `.crt-screen`/HUD; este spec (`specs/12-mobile-responsive.md`) cierra ese pendiente sin tocar `lib/games/touchInput.ts`, `components/game/TouchControls.tsx` ni las configs `*_TOUCH_CONFIG`.
- Corrió encadenado justo después de `skin-designer` en la misma sesión (spec `specs/game-jam/frogger/01-frogger-core.md`, motor real nuevo bajo `ranaria`) — el CSS/markup de `app/juegos/[id]/jugar/page.tsx`, `app/globals.css`, `components/GameCard.tsx`/`GameCardMini.tsx` ya traía los cambios de skins (selector condicionado por `isReal`, clases `.cover-*--neon`/`--retro`) al momento de auditar. No hubo conflicto: los cambios de mobile-porter (padding/wrap/viewport) son ortogonales a los de skin-designer (paletas de canvas + filtros CSS de cover).
- La corrida original murió justo antes de escribir esta memoria (expiró el login del agente a mitad de ejecución) — el spec `specs/12-mobile-responsive.md` y los cambios de código ya estaban completos y commiteados al working tree en ese punto; esta fila se completó manualmente desde el coordinador leyendo el spec ya escrito, más una verificación visual con Playwright a 375px (`/juegos/ranaria/jugar`, skins `clasico` y `retro`) que la corrida original no pudo hacer por no tener Playwright disponible en su entorno.
- **2026-08-04 (segunda corrida)** — Encargo puntual del usuario: verificar si RANARIA es jugable en un móvil real de punta a punta, no solo si el layout cabe. No se reauditó el layout (sin evidencia de cambio en `app/globals.css`/`app/juegos/[id]/jugar/page.tsx` desde la primera corrida) — el hallazgo nuevo es de input, no de CSS: RANARIA no tiene ningún camino táctil (ni `TouchControls` registrado en `TOUCH_CONFIGS`, ni listeners propios como los que sí tiene `bloque-buster`). No se implementó ningún control táctil (regla dura: territorio de spec 11). Sin acceso a Playwright en este entorno (`npx playwright` pidió instalar el paquete; `npm install` prohibido) — el hallazgo de input se confirmó por lectura de código (existencia/ausencia de listeners), no requiere verificación visual. Ver `specs/13-mobile-responsive.md`.
